# أوراق تمارين البرمجة — تأسيس بكالوريا ٢٠٢٧

أوراق تمارين تفاعلية لمادة **البرمجة** — الصف الثانى الثانوى، البكالوريا المصرية.

**الرابط:** https://youssef-eltohamy.github.io/programming-drills/

## إيه اللى فى كل ورقة

- **ثلاثون تمريناً** على المحاضرة واللى قبلها — المنهج تراكمى فالورقة تراكمية.
- **الإجابة والشرح** خلف زرارين منفصلين. الشرح خطوة بخطوة ومعاه رسم توضيحى لكل خطوة.
- **محرّر كود** شغّال جوه الصفحة نفسها — تكتب وتشغّل من غير ما تنزّل حاجة.
- **الإجابات بتتحفظ** على جهاز الطالب لوحدها.

## بتشتغل أوفلاين

كل ورقة **ملف واحد مكتفٍ بذاته** — التنسيق والرسوم والشعار والمحرّر كلهم جواه. يعنى الطالب يقدر:

- يفتحها بالرابط على طول، **أو**
- يحفظها من المتصفح (`Ctrl+S`) ويشتغل عليها من غير إنترنت خالص.

المحرّر بيشتغل جوه `Web Worker` معزول، فالحلقة اللانهائية بتتقطع بمهلة والصفحة ما بتعلّقش.

## الملفات

